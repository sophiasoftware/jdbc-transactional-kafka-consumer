# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it
privately using [GitHub's private vulnerability reporting](https://github.com/sophiasoftware/jdbc-transactional-kafka-consumer/security/advisories/new).

Please do not report security vulnerabilities through public GitHub issues.

## Disclosure Process

We will acknowledge new vulnerability reports within a few business days.
Once a vulnerability is confirmed, we will work on a fix and coordinate a
disclosure timeline with the reporter. We ask that reporters allow at least
90 days to address a vulnerability before any public disclosure, in line
with common coordinated disclosure practices.

## Supported Versions

Security fixes are applied to the latest released version of this library.
